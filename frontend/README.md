# Krypton Gateway Frontend

This is the React + Vite frontend for the Krypton Gateway Active-Defense dashboard.

For full project instructions (including how to run the FastAPI backend and Exploit Simulator), please refer to the [Main Project README](../README.md) located at the root of the repository.

## Running the Frontend Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open your browser and navigate to `http://localhost:5173`.
